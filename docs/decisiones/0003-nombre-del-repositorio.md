# Decisión 0003 — Nombre del repositorio

## Contexto

El repositorio original se llamaba `Exploracion_NOAA_2024`, lo que estaba asociado a
la primera etapa de un análisis limitado al año 2024 que hice a modo de aprendizaje.

La actualizacion busca convertir el trabajo en un proyecto de análisis
reproducible y presentable en portfolio, sin expandir todavía el alcance hacia
data engineering, automatización continua o múltiples fuentes.

## Decisión

El repositorio pasa a llamarse `analisis-eventos-NOAA`.

El año 2024 se mantiene como caso base del análisis, pero no como parte del
nombre del repositorio.

## Consecuencia

La tematicadel proyecto en sí pasa de “exploración de data del año 2024” a “Análisis reproducible de
eventos del dataset del NOAA”.
